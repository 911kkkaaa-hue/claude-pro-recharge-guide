## 九、FAQ：Claude 开通常见问题

**Q1：Claude Pro 多少钱一个月？**
官方 20美元/月（年付一次性 200美元，折合约 16.7美元/月）；国内代充价通常 150-190 元。

**Q2：Claude Max 多少钱？**
Max 5x 为 100美元/月、Max 20x 为 200美元/月，无年付折扣。

**Q3：Claude 代充会封号吗？**
正规代充走合规支付通道，账号风险主要来自异常登录与共享行为；代充属于平台条款灰区，介意者请走官方渠道。

**Q4：多久到账？**
自助开通一般几分钟内生效。建议开通后先等 10-20 分钟再启动 Claude Code，给官方系统同步额度留时间；期间尽量避免多设备同时登录或切换网络节点。

**Q5：5小时 Session 是怎么算的？**
从发第一条消息开始计时，5 小时到点自动重置配额；消息越长、上下文越深、高峰期扣额越快。网页/手机/桌面端共享同一配额。

**Q6：Max 是无限用吗？**
不是。Max 仍有 usage limits，只是额度池更大、优先级更高。宣称"无限用"的都是虚假宣传。

**Q7：API 开通能当会员用吗？**
不能。API 与订阅是两套体系，API 只用于 Console/Claude Code 程序调用。

**Q8：Claude Code 要单独付费吗？**
不用。Pro/Max 订阅自带 Claude Code 额度；重度使用建议 Max。

**Q9：续费怎么做？**
到期前回快充AI 再买一份套餐，按同样流程自己激活即可，与首充完全相同，不需要联系任何人。

**Q10：Claude 和 ChatGPT 怎么选？**
长文写作、代码（尤其 Claude Code）Claude 强；生态与多模态 ChatGPT 全；重度用户两个都持有很常见。
